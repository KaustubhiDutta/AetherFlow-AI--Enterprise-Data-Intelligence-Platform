# 🚀 AetherFlow AI – Enterprise Data Intelligence Platform

> **Transform messy business data into intelligent insights with AI-powered automation.**

AetherFlow AI is a modern, enterprise-inspired **AI Data Automation Platform Landing Page** built for a frontend hackathon. It showcases how an enterprise SaaS platform can automate the complete data lifecycle—from ingestion and cleansing to AI-driven analysis and monitoring—through a premium, responsive, and highly interactive user interface.

1. 📂 Upload data (CSV, Excel, JSON, Google Sheets)

3. 🧠 AI analyzes trends and detects anomalies

# 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/KaustubhiDutta/AetherFlow-AI--Enterprise-Data-Intelligence-Platform.git
```

Navigate into the project:

```bash
cd AetherFlow-AI--Enterprise-Data-Intelligence-Platform
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
